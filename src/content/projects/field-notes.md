This page is **demonstration content**. It exists so you can see how a short project entry looks
without a case study attached — no metrics, no invented achievements, just a description and the
links you would actually want.

Short entries are the right shape for utilities, experiments, coursework and anything where the
interesting part is the thing itself rather than the decisions behind it.

## When to use this format

Use a short entry when the project is:

- **Small or self-contained** — a script, a component, a single-page tool.
- **Finished** — there is nothing left to explain about the trade-offs.
- **Better demonstrated than described** — a live link says more than three paragraphs.

Switch to the long format by adding a `caseStudy` block to the frontmatter. The page layout
adapts automatically: the project page grows a contents rail and a set of headed sections, and the
card links to "Read the case study" instead of "View project".
